## 🚀 Despliegue en GitHub Pages (Paso a Paso)

1. En tu repositorio de GitHub: [https://github.com/Santiago04-web/Kodigoo](https://github.com/Santiago04-web/Kodigoo)
2. Ve a la pestaña **Settings** (Configuración) > **Pages**.
3. En **Build and deployment > Source**, selecciona **Deploy from a branch**.
4. En **Branch**, selecciona `main` (o `master`) y carpeta `/(root)`, luego haz clic en **Save**.
5. Si vas a vincular tu dominio `kodigoo.lat`:
   * Verifica que en **Custom domain** aparezca `kodigoo.lat`.
   * En tu proveedor de DNS (Cloudflare, Namecheap, GoDaddy, etc.), apunta los registros DNS:
     * `A` apuntando a las IPs de GitHub Pages: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
     * `CNAME` para `www` apuntando a `santiago04-web.github.io`.
   * Marca la casilla **Enforce HTTPS**.
